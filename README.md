# bili-feed2later-extension

非官方浏览器插件（Chrome / Edge MV3）：定时检查哔哩哔哩关注 UP 的新视频，自动加入「稍后再看」，并推送通知。

把"追更"变成一个被动动作：白天每隔两小时自动看一眼关注动态，有新视频就收进稍后再看，等你有空统一看。已处理过的视频有完整的状态记录——你手动移除的、UP 删掉的，都不会再被重复添加。

## 功能

- 白天（默认 8–22 点）每 2 小时自动检查关注动态，新视频自动加入稍后再看
- 汇总通知：飞书群机器人 / Telegram / Bark（可配铃声、级别、分组等）/ 自定义 webhook
- 稍后再看对账：手动移除的视频永不再加；UP 删除的稿件自动跳过
- UP 黑名单、试运行 dry-run
- 工具栏弹窗：快捷开关、立即检查、状态信息；深浅色跟随系统
- 首次运行只建立基线不回填，避免一次塞满 100 条上限

## 安装

1. 从 [Releases](../../releases) 下载 zip 并解压（或 `git clone` 本仓库）
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」
3. 「加载已解压的扩展程序」选择解压出的目录
4. 先在浏览器登录 B站，点击工具栏图标即可使用

零构建：原生 HTML/JS，无需安装任何依赖。

## 隐私

插件不保存任何 Cookie / 账密，直接使用浏览器自身登录态；全部数据存储在本机 `chrome.storage`。
